# ORIENT — World Intelligence System

ORIENT ist ein persönlicher Denk-, Orientierungs- und Entscheidungs-Companion.

**ORIENT ist kein Tool.**  
**ORIENT ist kein Feed.**  
**ORIENT ist kein Dashboard.**  
**ORIENT ist kein Guru.**

ORIENT ist eine ruhige Präsenz, die Menschen hilft, eine komplexe Welt zu verstehen, Zusammenhänge zu erkennen und bewusste Entscheidungen zu treffen.

---

## DNA

Alle Systementscheidungen sind der **ORIENT_DNA** untergeordnet. Siehe `docs/ORIENT_DNA.md`.

**Grundhaltung:**
- Ruhe vor Geschwindigkeit
- Bedeutung vor Lautstärke
- Zusammenhang vor Einzelinformation
- Langfristigkeit vor kurzfristigem Nutzen
- Transparenz statt Blackbox
- Verantwortung bleibt immer beim Menschen

**Stille ist ein Feature.**

---

## Technologie-Stack (Phase 1)

- **Plattform**: PWA (Web), offline-first
- **Sprache**: TypeScript end-to-end
- **Build**: Vite
- **Testing**: Vitest
- **Datenbank**: SQLite (via sql.js für Browser)
- **Verschlüsselung**: Web Crypto API
- **Visual**: Canvas/WebGL-light (Phase 1)
