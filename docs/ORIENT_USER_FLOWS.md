# ORIENT — User Flows (Day 1 / Day 30 / Year 3)

Dieses Dokument beschreibt das Erlebnis von ORIENT über Zeit.
Ziel: Gefühl + Verhalten + Systemmechanik in konkreten Abläufen.

---

## Flow 0 — App öffnen (immer)

- Dunkler/heller Raum, ruhige Präsenz
- Zentrales Licht / lebendiger Denkraum
- Keine UI-Last, kein Feed, kein Druck
- ORIENT wartet auf Interaktion

---

## Day 1 — Kennenlernen (leise, nicht aufdringlich)

### 1) Erster Impuls (Alltag)
User: „Ich brauche Ideen für Silvester-Deko, aber bitte nicht kitschig."

ORIENT:
- legt Impulse an (Staub)
- erzeugt/erkennt Thread „Feiern & Gestaltung"
- fragt maximal 1 Rückfrage, wenn nötig:
  - „Eher elegant oder verspielt?"
- liefert 3–6 Vorschläge als Cluster (kein Linkdump)
- Visual: lokales Glimmen, erste Ader wächst

### 2) Kontext setzen (Respekt)
User: „Ich bin bei meiner Familie, die nächsten 3 Tage bitte Ruhe."

ORIENT:
- erstellt Context Snapshot (mode=FAMILY, intensity_cap=1/day)
- sagt kurz: „Verstanden."
- keine weiteren Pushes
- wenn User aktiv fragt → normal reagieren

### 3) Mini-Export (optional)
User: „Fass mir die Deko-Ideen kurz zusammen."

ORIENT:
- erstellt Snapshot Export (mode=OVERVIEW)
- liefert Markdown/Text, kurz, nutzbar

## Day 30 — Muster, Tiefe, weniger Geräusch

### 1) Reaktivierung (ohne Nervigkeit)
User: „Nächste Party. Keine Origami-Schwäne diesmal."

ORIENT:
- erkennt Thread-Verlauf (Origami → Party → Stil)
- schlägt anschlussfähige Alternativen vor (Wunderkerzen-Servietten etc.)
- zeigt: ein anderer Bereich leuchtet, Origami bleibt im Hintergrund

### 2) Thema-Sprung per Sprache
User: „Mir fällt gerade was zum Trading ein."

ORIENT:
- fokussiert Trading-Thread (Arm/Knoten leuchtet)
- zeigt temporäres HUD:
  - Stabil / kritisch / kippt
  - Szenarien & Unsicherheiten
  - „Beobachten / Prüfen / Risiko sichtbar machen"
- keine Automatisierung, keine Garantien

### 3) Quellengewicht sichtbar machen
User: „Ich habe da was auf Instagram gesehen…"

ORIENT:
- speichert Claim als RUMOR/THESIS
- markiert Source als UNDERGROUND/SOCIAL
- sagt klar:
  - „Das ist ein Frühindikator, kein Beweis."
- bietet an:
  - „Soll ich prüfen, ob es unabhängige Bestätigungen gibt?"

### 4) Kartensystem ohne Klick-Zwang
User: „Der Trump-Stream nervt. Weg damit."

ORIENT:
- reduziert entsprechende Karte/HUD-Aktivität
- merkt Präferenz (nicht wieder aufdrängen)
- Thread bleibt erhalten, aber wird gedimmt / dormant, wenn keine Nutzung

## Year 3 — Tiefe Beziehung, Langzeitgedächtnis, echte Verknüpfung

### 1) Wiederkehr nach Jahren
User: „Ich hatte doch mal diese Idee… irgendwas mit Space Shuttle."

ORIENT:
- findet alten Thread/Impulse (DORMANT)
- fragt vorsichtig:
  - „Meinst du die Idee von 2023-11? Soll ich sie öffnen?"
- bei Zustimmung:
  - reaktiviert Thread (DORMANT → ACTIVE)
  - zeigt Wachstum: neue Adern verbinden aktuelle Projekte mit dem alten Arm

### 2) Kontextualisierte Vorschläge (nicht übergriffig)
User: „Ich will daraus was entwickeln."

ORIENT:
- schaltet Verdichtungsmodus BUILD ein
- liefert:
  - strukturierte Anforderungen
  - offene Fragen
  - nächste Schritte
- optional Export:
  - README für Cursor
  - Präsi-Outline

### 3) Multimodal „Greifbar machen"
User: „Kannst du mir dazu ein Bild generieren?"

ORIENT:
- erzeugt Prompt aus:
  - gespeicherten Features
  - Stil/Absicht
  - früheren Varianten
- Bild ist Referenz (kein Fakt)
- erzeugtes Medienobjekt wird als Impuls/Attachment im Thread gespeichert

### 4) Kontext bleibt König
User: „Ich bin gerade überfordert, heute nur kurz."

ORIENT:
- setzt Context Snapshot (mode=QUIET, intensity_cap=low)
- antwortet knapper, weniger Optionen
- verschiebt tiefe Verdichtung auf später, ohne Druck

---

## Always-on Prinzipien (in jedem Flow)

- Keine Endlosfeeds
- Pull statt Push
- Stufen eskalieren über Vertrauen, nicht über Event-Hype
- Gedanken werden nicht automatisch gelöscht
- ORIENT zeigt Unsicherheit sichtbar
- ORIENT bleibt Companion, kein Kontrollsystem
