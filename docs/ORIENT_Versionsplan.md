# ORIENT — Versionsplan

*Version 0.1 — Der Weg von klein zu vollständig.*
*Jede Version ist rund in sich. Keine ist unfertig.*

---

## Das Prinzip

Version 1 ist nicht Version 10 minus neun Zehntel.
Version 1 ist ORIENT — klein, aber vollständig.

Jede Version fügt ein Modul hinzu.
Module sind unabhängig — sie hängen sich an das Bestehende.
Das Fundament bleibt immer gleich.

---

## Version 1.0 — Das Fundament

*"Ein intelligenter Raum der zuhört und mitdenkt."*

**Was es kann:**
— Die Bubble — lebendig, dreidimensional, reagiert auf Zustand
— Spracheingabe — Press & Hold, Gedanke wird aufgenommen
— Ideenspeicher — jede Idee landet sicher, nichts geht verloren
— Morgenroutine — freundliche Begrüßung, Tagesstruktur, was steht an
— Abendritual — gute Nacht, letzte Frage, loslassen
— Onboarding — drei Wege rein, eigener Name, Persönlichkeits-Abfrage
— Offline-First — funktioniert immer, sync wenn online
— Basis-Behavior-Engine — Aktivität, Fokus, Müdigkeit erkennen

**Was es noch nicht kann:**
Alles andere.

**Wie es sich anfühlt:**
Ein Companion der da ist. Der zuhört. Der nicht nervt.
Man spricht — er merkt es sich. Man schläft — er denkt weiter.
Morgens liegt ein erster Gedanke bereit.

**Technisch:**
React + Vite + Dexie lokal
Supabase als Backend
Anthropic API für Verarbeitung
Node.js API-Schicht

— Personalisierte News — gefiltert, mit Quellentemperatur

— Zeitachse — erste historische Einordnung von Themen

**Wie es sich anfühlt:**
ORIENT weiß was dich interessiert.
Es bringt Dinge die du nicht gesucht hast — aber sofort erkennst.

## Version 10.0 — Die Welt

*"ORIENT verbindet Menschen um gemeinsam mehr zu schaffen."*

**Neu hinzu:**
— Vollständiges kollektives Netz — Sphären berühren sich
— Unternehmens-Verbindungen — drei Firmen die nichts voneinander wissen
— Gesellschaftlicher Seismograph — Chancen für die Welt sehen
— Selbst-Extension — ORIENT ergänzt sich wo Lösungen fehlen

**Wie es sich anfühlt:**
Es macht mehr Spaß miteinander zu arbeiten als gegeneinander.
Das spürt man.

---

## Die Regel

Kein Modul der nächsten Version wird gebaut
bevor die aktuelle Version rund ist.

Klein. Stark. Dann wachsen.
